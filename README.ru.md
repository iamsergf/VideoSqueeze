# VideoSqueeze

[English](README.md) · **Русский**

Маленькое нативное приложение для macOS, которое сжимает видео. Перетащите файлы в окно, нажмите **«Сжать»** и получите уменьшенные MP4 рядом с оригиналами.

Используется аппаратный видеокодер Apple (VideoToolbox). На Mac с Apple Silicon минута видео 1080p сжимается за несколько секунд, а вентиляторы не включаются.

## Возможности

- **Перетаскивание** одного или сразу нескольких видео (MOV, MP4, M4V и всё, что воспроизводит macOS)
- **Два режима**
  - **По качеству**: выберите «Высокое», «Среднее» или «Низкое» и максимальное разрешение
  - **По размеру**: «не больше N МБ», например 5 МБ для мессенджера или почты. Приложение само подбирает битрейт, разрешение и при необходимости частоту кадров. Потом проверяет результат и перекодирует файл, если он всё-таки превысил лимит
- Кодеки **HEVC (H.265)** и **H.264**
- Сохраняется поворот видео с телефона и HDR с iPhone (10-битный HEVC)
- Битрейт никогда не становится выше, чем у оригинала
- Универсальное приложение для Apple Silicon и Intel, весит около 1 МБ

## Скачать

1. Скачайте **VideoSqueeze.zip** со страницы [последнего релиза](../../releases/latest).
2. Распакуйте архив и перенесите **VideoSqueeze.app** в «Программы».
3. При первом запуске macOS заблокирует приложение: оно не нотаризовано в Apple, для этого нужен платный аккаунт разработчика. Чтобы разрешить запуск, сделайте одно из двух:
   - Попробуйте открыть приложение, затем откройте **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз и нажмите **«Всё равно открыть»**.
   - Или выполните в Терминале:
     ```bash
     xattr -dr com.apple.quarantine /Applications/VideoSqueeze.app
     ```

Нужна **macOS 14 Sonoma** или новее.

## Сколько видео влезет в N МБ?

Размер файла ≈ битрейт × длительность. Поэтому чем длиннее видео, тем ниже качество при том же размере. Примерные цифры для лимита 5 МБ:

| Длина видео | Доступный битрейт | Результат |
|---|---|---|
| 30 сек | ~1,3 Мбит/с | хорошее 720p–1080p |
| 2 мин | ~330 кбит/с | терпимое 360p–480p |
| 10 мин | ~65 кбит/с | 144p с пониженной частотой кадров, годится только для пересылки |

## Сборка из исходников

Нужна Xcode (или Xcode Command Line Tools с macOS SDK).

```bash
git clone https://github.com/iamsergf/VideoSqueeze.git
cd VideoSqueeze
./build.sh
```

Приложение появится в `build/VideoSqueeze.app`, архив для релиза — в `build/VideoSqueeze.zip`.

Есть и консольный режим для скриптов:

```bash
build/VideoSqueeze.app/Contents/MacOS/VideoSqueeze --cli input.mov output.mp4 size=5
```

Параметры: `size=<МБ>` включает режим по размеру, `h264` выбирает кодек H.264, `720` ограничивает разрешение до 720p.
